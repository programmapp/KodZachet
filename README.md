# КодЗачёт

Тренажёр к промежуточному контролю по программированию: 8 лекций, 200 вопросов, мгновенная проверка, история попыток и кабинет преподавателя.

Интерфейс полностью на русском языке.

## Запуск

```bash
npm run dev
npm run build
npm run typecheck
```

База поднимается сама: в предпросмотре это встроенный Postgres, на публикации — выделенная база. Схема лежит в `migrations/0002_exam.sql`.

## Переменные сервера

Их задают в окружении сервера, не в коде страницы и не в файле, который попадает в браузер.

| Переменная | Назначение |
| --- | --- |
| `BOT_TOKEN` | Токен Telegram-бота от @BotFather |
| `ADMIN_CHAT_ID` | Чат, куда приходят уведомления о регистрации |
| `ADMIN_PASSWORD` | Необязательно. Если задан, это пароль кабинета преподавателя |

Если `BOT_TOKEN` или `ADMIN_CHAT_ID` нет, регистрация всё равно сохраняется, а в журнал сервера пишется, что уведомление не отправлено.

## Telegram

1. В Telegram откройте @BotFather и выполните `/newbot`.
2. Скопируйте токен в `BOT_TOKEN`.
3. Напишите боту любое сообщение со своего аккаунта.
4. Узнайте числовой `chat_id` (например, через `getUpdates`) и положите его в `ADMIN_CHAT_ID`.
5. Уведомление уходит только с сервера и только при первой регистрации пары «имя + группа». Обновление страницы повторное сообщение не создаёт.

Текст уведомления:

```text
🎓 Новый студент зарегистрировался!
👤 Имя и фамилия: …
👥 Учебная группа: …
📅 Дата регистрации: …
🕒 Время регистрации: …
```

Время в уведомлении — часовой пояс Asia/Tashkent (UTC+5).

## Кабинет преподавателя

Адрес: `/admin`. Ссылка есть на странице «О платформе», в меню студента её нет.

Если `ADMIN_PASSWORD` не задан, первый вход предлагает создать пароль. Он хранится как хеш. Обычный студент этот список не видит.

## Запуск в Windows (VS Code)

1. Откройте папку проекта в VS Code.
2. В терминале выполните `npm install` (один раз).
3. Выполните `powershell -ExecutionPolicy Bypass -File .\\start-local.ps1`.
4. Вставьте НОВЫЙ токен бота, полученный после отзыва старого токена через @BotFather.
5. Откройте адрес, который покажет Vite (обычно `http://localhost:8080`).

Скрипт `start-local.ps1` уже задаёт `ADMIN_CHAT_ID=5363836876`. Токен запрашивается при запуске и не записывается в файлы проекта. Не публикуйте токен и не отправляйте его другим людям.
